# مسیریاب هوشمند

افزونهٔ مرورگر (Chrome / Edge) برای **مسیریابی هوشمند ترافیک**: سایت‌های ایرانی مستقیم باز می‌شوند و بقیهٔ سایت‌ها از **پروکسی محلی فیلترشکن** عبور می‌کنند — بدون نیاز به روشن بودن VPN روی کل سیستم.

## این افزونه چه کاری می‌کند؟

- **مسیریابی خودکار**: دامنه‌های `.ir` و فهرست بزرگی از سایت‌های ایرانی (دیجی‌کالا، آپارات، دیوار و…) مستقیم می‌مانند؛ بقیه از تونل رد می‌شوند.
- **کنترل دستی هر سایت**: برای هر سایت می‌توانی «بدون پروکسی» یا «با پروکسی» را انتخاب کنی و همان تصمیم برای همیشه ذخیره می‌شود.
- **مسیر موقتِ همین تب**: تغییر مسیر فقط برای ۱۰ دقیقه یا تا بسته‌شدن تب، بعد خودکار برمی‌گردد.
- **تشخیص خودکار پروکسی**: آدرس و پورت پروکسی محلی را خودش پیدا می‌کند و نوعش (SOCKS5 / HTTP / …) را تشخیص می‌دهد.
- **پایداری اتصال**: اگر تونل محلی قطع شود، پورت فعال دیگری پیدا می‌کند و موقتاً روی آن سوئیچ می‌شود و بعد برمی‌گردد.
- **شناسایی جغرافیایی (اختیاری)**: سایت‌هایی که IP سرورشان در ایران است، هنگام گشت‌وگذار مستقیم می‌شوند.
- **تمیز و بومی**: رابط فارسی و راست‌به‌چپ با طراحی سبک و مینیمال.

## چطور کار می‌کند؟

هستهٔ افزونه یک تابع `routeFor()` در `shared.js` است که برای هر دامنه تصمیم «مستقیم یا پروکسی» می‌گیرد. همین تابع هم در پاپ‌آپ (برای نمایش)، هم در سرویس‌ورکر و هم در اسکریپت PAC استفاده می‌شود؛ پس آنچه در پاپ‌آپ می‌بینی دقیقاً همان چیزی است که مرورگر اجرا می‌کند.

 ترتیب اولویت تصمیم‌گیری:
1. قانون «یادگرفته» برای همان دامنه (انتخاب دستی تو)
2. فهرست «همیشه با پروکسی»
3. فهرست «همیشه مستقیم»
4. پسوند `.ir` و فهرست پیش‌فرض سایت‌های ایرانی
5. تطابق دامنهٔ آینه‌ای برندهای ایرانی
6. تشخیص جغرافیایی (اگر روشن باشد)
7. پیش‌فرض بر اساس حالت انتخاب‌شده

## پیش‌نیاز

این افزونه VPN سراسری را **مدیریت نمی‌کند**. باید فیلترشکن را طوری تنظیم کنی که یک **پروکسی محلی** ارائه دهد (معمولاً `127.0.0.1` روی پورت `1080` یا `7890`). نرم‌افزارهایی مثل Clash، v2rayN، Nekoray، Hiddify و مشابه معمولاً SOCKS5 محلی دارند.

> ⚠️ اگر VPN روی **کل سیستم** روشن باشد، مرورگر نمی‌تواند یک سایت را از تونل بیرون بگذارد. اول VPN سراسری را خاموش کن و فقط پروکسی محلی فیلترشکن را بالا نگه دار.

## نصب

### نصب دستی (توسعه)
1. به `chrome://extensions` برو.
2. **Developer mode** را روشن کن.
3. روی **Load unpacked** بزن و پوشهٔ همین پروژه را انتخاب کن.

برای Edge: `edge://extensions` و همان مراحل.

## راه‌اندازی سریع

1. VPN سراسری را خاموش کن و پروکسی محلی فیلترشکن را روشن بگذار.
2. آیکون افزونه را بزن و روی **«تشخیص خودکار پروکسی»** یا در صفحهٔ تنظیمات همان دکمه را بزن.
3. اگر پیدا نشد، در صفحهٔ تنظیمات آدرس و پورت را دستی وارد کن و **ذخیره** بزن.
4. تمام — حالا سایت‌های ایرانی مستقیم و بقیه از تونل باز می‌شوند.

## استفاده

- **حالت‌های سه‌گانه**:
  - **هوشمند** — ایرانی‌ها مستقیم، بقیه از پروکسی.
  - **پروکسی** — همه‌چیز از تونل.
  - **مستقیم** — همه‌چیز بدون تونل.
- **برای سایت فعلی**: دکمه‌های «بدون پروکسی» / «با پروکسی» — ذخیرهٔ دائمی و اولویت‌دار بر همه‌چیز.
- **موقت (همین تب)**: «از پروکسی / مستقیم» — تا ۱۰ دقیقه یا بسته‌شدن تب، بعد خودکار برمی‌گردد.

## تشخیص خودکار پروکسی (چطور مطمئن می‌شود)

- **اول تنظیمات خود مرورگر** خوانده می‌شود؛ اگر فیلترشکن پروکسی سیستم را ست کرده باشد، افزونه همان را می‌خواند و تأیید می‌کند — بدون اسکن و بدون تغییر شبکه.
- در غیر این صورت پورت‌های رایج روی `127.0.0.1` به‌ترتیب بررسی می‌شوند: ۱۰۸۰، ۷۸۹۰، ۷۸۹۱، ۷۸۹۷، ۲۰۸۰، ۸۸۸۸، ۱۰۸۰۸، ۱۰۸۰۹، ۱۰۸۷، ۸۱۱۸، ۸۰۸۰، ۹۰۵۰ و چند مورد دیگر.
- **صحت تشخیص**: صرفاً «درخواست موفق» کافی نیست. افزونه IP مستقیم و IP خروجی از تونل را می‌خواند و فقط وقتی پورتی را می‌پذیرد که این دو **متفاوت** باشند؛ وگرنه نتیجه «پروکسی نیست» است.
- **نوع پروکسی**: هر پورت با ترتیب `SOCKS5 → HTTP → SOCKS4 → HTTPS` آزمایش می‌شود و پیشنهاد نهایی SOCKS5 است.

## ساختار پروژه

```
manifest.json     تنظیمات افزونه (Manifest V3)
background.js     سرویس‌ورکر: مسیریابی، تشخیص، پایداری تونل، جغرافیا
shared.js         هستهٔ تصمیم مسیریابی (routeFor) + ساخت PAC
popup.html/css/js پاپ‌آپ
options.html/css/js صفحهٔ تنظیمات
defaults.js       مقادیر پیش‌فرض + فهرست سایت‌های ایرانی
detect.js         تست و تشخیص پروکسی
theme.css         توکن‌های رنگ و طراحی مشترک
icons/            آیکون‌های افزونه
fonts/            فونت فارسی Vazirmatn
```

## محدودیت‌ها

- **per-tab واقعی ممکن نیست** (Manifest V3): `chrome.proxy` فقط سراسری است؛ پس «موقت» یعنی کل مرورگر و بازگشت خودکار.
- اگر کل اینترنت قطع باشد، تشخیص نمی‌تواند «پروکسی نیست» را از «شبکه قطع است» جدا کند و صراحتاً می‌گوید «نتیجه قابل اعتماد نیست».
- اگر افزونهٔ دیگری پروکسی را کنترل کند، پیام «درخواست‌ها از پروکسی عبور نکردند» نمایش داده می‌شود.

## حریم خصوصی

افزونه هیچ حسابی نمی‌سازد و هیچ داده‌ای را به سرور خودش نمی‌فرستد. برای خواندن IP عمومی (فقط هنگام تشخیص پروکسی و هنگام روشن بودن «تشخیص با موقعیت سرور») از سرویس‌های عمومی مثل ipify، ifconfig.me، icanhazip و ipwhois.app استفاده می‌کند. تنظیمات و فهرست‌های تو فقط به‌صورت محلی در `chrome.storage` ذخیره می‌شوند.

## توسعه

پس از هر تغییر، در `chrome://extensions` روی **Reload** بزن. نسخهٔ نمایش‌داده‌شده در پایین پاپ‌آپ (`BUILD_TAG` در `defaults.js`) برای تأیید بارگذاری درست است.
